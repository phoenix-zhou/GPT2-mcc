# Security Policy / 安全策略

## Supported version / 支持版本

Security fixes target the current `main` branch. The original upstream GPT-2
snapshot and historical commits are retained for provenance and are not
supported as production software.

安全修复只面向当前 `main`。原始 GPT-2 上游快照与历史提交仅作来源记录，不作为
生产软件提供安全支持。

## Reporting a vulnerability / 报告漏洞

Please use the repository owner's private GitHub security-advisory channel when
available. Do not open a public issue containing an exploit, credential,
personal information, or health data. Include the affected revision, minimal
reproduction, impact, and suggested mitigation, using synthetic data only.

请优先使用仓库所有者的 GitHub 私密 Security Advisory 渠道。不要在公开 Issue 中
提交利用代码、密钥、个人信息或健康数据。报告应包含受影响版本、最小复现、影响和
修复建议，并且只能使用合成数据。

## Scope and emergency disclaimer / 范围与急症声明

This is a research portfolio, not a monitored clinical service. Do not report a
medical emergency through repository channels; contact local emergency services.
The maintainers make no clinical, compliance, or response-time guarantee.

本项目是研究作品集，不是持续值守的医疗服务。医疗急症请联系当地急救服务，不要
通过仓库渠道报告。维护者不作临床、合规或响应时限保证。

See [the current security and risk review](docs/security-and-risk-review.md) for
implemented controls, verification, and known residual risks.
